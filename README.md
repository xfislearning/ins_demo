# KRF Risk Intelligence Prototype

## Open the prototype

1. Unzip the package.
2. Open `dist/index.html` in Microsoft Edge or Google Chrome.
3. Select **Load sample business** to see a completed example.
4. Continue to generate the draft Business Risk Snapshot.
5. Use **Print / Save PDF** to export the generated report.

## What is implemented

- Interactive four-step Intelligent Risk Snapshot questionnaire
- Conditional discussion-area rules
- Draft report generation and print view
- Clickable Commercial Trigger Intelligence weekly-scan and review simulation
- Clickable Client Risk Change comparison and confirmation simulation
- Responsive desktop and mobile layout

## Prototype boundary

The prototype runs entirely in the browser. It does not transmit or retain submitted information and does not call an LLM. A production pilot would add a secure backend, structured LLM API output, human approval, audit history, and appropriate privacy controls.
